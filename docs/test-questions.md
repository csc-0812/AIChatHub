## 使用方式

### 前端测试
在聊天界面直接输入上述问题即可，系统会根据 prompt 自动路由到对应工具。

### API 测试
```bash
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "生成计划执行报表"}],
    "stream": false
  }'
```

### 典型参数示例

**报表生成**：`{"report_type": "产能分析报表", "start_date": "2024-06-01", "end_date": "2024-06-10"}`

**结果推演**：`{"scenario": "产能调整", "variables": {"产线": "涂装产线C", "调整类型": "增加班次", "调整量": 2}}`

**根因分析**：`{"problem": "工期延误", "indicators": ["达成率", "交付准时率"]}`
